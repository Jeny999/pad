# Pad

**Phone as a gamepad for your PC · Телефон как геймпад для ПК**

[Русский](README.ru.md) · [English](README.en.md)

![How it works](docs/connection.en.png)

Pad is a standalone local project: a small Windows server plus an Android app/web page. The phone sends stick and button state over Wi-Fi; the PC exposes a virtual **Xbox 360** controller through ViGEmBus. No accounts, cloud or AI.

![Phone gamepad](docs/mockups/phone.en.png)
