PAD

Connect in 4 steps

From the server window to the game — no cables, no cloud.

HOME WI-FI ONLY
ACCESS CODE REQUIRED
1

Start the server

The PC address and access code appear in the window. The phone and PC must be on the same Wi-Fi.

2

Enter address and code

Open Pad on the phone, enter an address like 192.168.0.105:8090 and the code from the server window.

3

Connect

Tap “Connect”. Status “connected” and a ping value mean the game already sees the Xbox controller.

4

Make it yours

Button size, shape, stick sensitivity, rumble and screen quality — all in the gear menu.
